# Lisensi Dokumen

Isi folder `kebijakan/`, `dokumen/`, `agen/`, dan berkas README di repositori ini berlisensi Creative Commons Atribusi 4.0 Internasional (CC BY 4.0): <https://creativecommons.org/licenses/by/4.0/deed.id>.

Anda boleh menyalin, menyebarkan, mengubah, dan memakai dokumen ini untuk keperluan apa pun, termasuk komersial, dengan syarat mencantumkan atribusi kepada Muhammad Edya Rosadi sebagai pembuat kerangka ini, menautkan lisensinya, dan menyatakan bila ada perubahan.

Templat yang sudah Anda isi untuk perguruan tinggi atau mata kuliah Anda tidak perlu mencantumkan atribusi di naskah resminya. Atribusi cukup dicantumkan bila templat itu dibagikan ulang sebagai templat.

Kode program (folder `alat/`, `audit/`, `uji/`, dan skema JSON) berlisensi MIT, lihat [LICENSE](LICENSE).
