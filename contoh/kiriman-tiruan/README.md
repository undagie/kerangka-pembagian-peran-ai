# Kiriman Tiruan

Semua kiriman di folder ini dibuat untuk uji dan latihan. Tidak ada karya mahasiswa sungguhan.

| Folder | Kiriman | Keadaan yang diuji |
|---|---|---|
| `tugas-p01` | A01 | Lengkap dan benar |
| `tugas-p01` | A02 | `hello.cpp` tidak ada, berkas `.exe` ikut tersimpan, pembagian bilangan bulat, tanpa `.gitignore` |
| `tugas-p01` | A03 | Sama dengan A01, dengan `catatan_kesalahan.md` yang identik |
| `uraian` | U01 | Jawaban lengkap |
| `uraian` | U02 | Jawaban sebagian dengan contoh pemilihan yang tidak acak |
| `uraian` | U03 | Identik dengan U01 |
| `uraian` | U04 | Kosong |

Berkas `heloo.exe` di A02 hanyalah berkas teks bernama `.exe` untuk menguji cek berkas terlarang.

Kunci untuk `tugas-p01` adalah [contoh/kunci/P01_Dari_Python_ke_Cpp.json](../kunci/P01_Dari_Python_ke_Cpp.json), dan rubrik untuk `uraian` adalah [contoh/rubrik/Uraian_Umum_Sampel_Acak.json](../rubrik/Uraian_Umum_Sampel_Acak.json).
